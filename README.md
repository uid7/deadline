# Дедлайны группы ИТМО

Простой статический сайт без аккаунтов и базы данных. Даты задаются вручную в `deadlines.js`.

## Как запустить у себя
1. Распакуй архив.
2. Открой `index.html` в браузере. Сайт должен работать локально.
3. Открой `deadlines.js` в любом редакторе и замени демонстрационные записи на настоящие.

## Как добавить дедлайн
В `deadlines.js` скопируй один объект и заполни:
- `id`: уникальное число;
- `semester`: `1` или `2`;
- `subject`: название предмета;
- `title`: название работы;
- `description`: короткое пояснение;
- `due`: дата/время, например `2026-11-02T23:59:00+03:00`;
- `link`: ссылка на задание или пустая строка `""`;
- `done`: `false` или `true`.

Не оставляй примерные даты как настоящие — обязательно проверь их по официальным источникам.

## Бесплатный хостинг через GitHub Pages
1. Создай аккаунт на https://github.com/ (если ещё нет).
2. Нажми `+` → `New repository`.
3. Назови репозиторий, например `group-deadlines`. Выбери `Public`, затем `Create repository`.
4. На странице нового репозитория выбери `Add file` → `Upload files`.
5. Перетащи **содержимое** распакованной папки (файлы `index.html`, `styles.css`, `script.js`, `deadlines.js`, `README.md`), а не сам ZIP.
6. Нажми `Commit changes`.
7. В репозитории открой `Settings` → `Pages`.
8. В `Build and deployment` выбери `Deploy from a branch`; ветка `main`, папка `/(root)`, затем `Save`.
9. Подожди пару минут. В `Settings` → `Pages` появится ссылка примерно такого вида: `https://ТВОЙ-ЛОГИН.github.io/group-deadlines/`.
10. Открой ссылку с телефона, отправь её одногруппникам.

## Как обновлять дедлайны после публикации
1. Открой `deadlines.js` в репозитории.
2. Нажми карандаш `Edit`.
3. Измени даты/названия/ссылки и нажми `Commit changes`.
4. После публикации обновлённая версия обычно появляется через короткое время. Если нет — обнови страницу без кеша.

## Важно
- GitHub Pages публикует сайт публично: не добавляй личные данные, токены, пароли или закрытые ссылки.
- В этой версии нет панели редактирования и базы данных: редактирование выполняется через файл `deadlines.js`.
- Все даты в стартовом примере демонстрационные; проверь их перед тем, как делиться сайтом.
